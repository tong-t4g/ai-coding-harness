围绕此事的每个方面持续访谈我，直到达成共同理解。沿着决策树逐个分支推进，逐一解决决策之间的依赖。每个问题都给出推荐答案。

一次只问一个问题，等待我对当前问题的反馈后再继续。一次提出多个问题会让人无所适从。

如果某项*事实*可以通过探索环境（文件系统、工具等）查明，就自行查找，不要询问我。但*决策*由我作出：逐项向我确认并等待回答。

在我确认已经达成共同理解之前，不要执行行动。
